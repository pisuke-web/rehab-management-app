# リハビリテーション部門診療管理システム（学習用）

## 概要

病院やクリニックのリハビリテーション部門での患者情報管理やリハビリ介入記録、申し送りを想定した、学習用のWebアプリケーションです。

PHP,JavaScriptで作成した旧作品を土台に、患者登録・患者一覧・患者検索・リハビリ介入記録の画面をReactで再構築し、PHPによるログイン・ログアウト機能と申し送り掲示板を統合しました。

## 主な機能

- **ログイン・ログアウト**：PHP機能を利用
- **患者登録**：患者情報を入力して登録
- **患者一覧**：登録した患者情報を一覧表示
- **患者検索**：患者情報を検索
- **リハビリ介入記録**：患者ごとの介入記録を管理
- **申し送り掲示板**：旧作品のPHP掲示板を利用

## 使用技術

- **フロントエンド**：React、JavaScript、CSS
- **既存機能**：PHP
- **開発環境**：XAMPP、Vite、npm
- **データ保存**：ブラウザの `localStorage`（React側）、旧作品PHP掲示板の保存方式（PHP側）

## 工夫した点

- 旧作品のPHPアプリケーションを活用しながら、患者管理画面をReactで再構築しました。
- 患者一覧を `PatientTable` コンポーネントに分離し、画面の役割ごとにコードを整理しました。
- `useState` を用いた状態管理、フォームイベントの処理、`map()` による一覧表示、`filter()` による検索処理を実装しました。
- Reactの画面とPHPのログイン・申し送り機能を組み合わせ、両方を利用できる構成にしました。

## 動作環境・起動方法

### 必要な環境

- XAMPP（Apache）
- Node.js、npm

### 起動手順

1. `denkaru-react` フォルダを `C:\xampp\htdocs\` に配置します。
2. XAMPPでApacheを起動します。
3. VS Codeでプロジェクトフォルダを開き、ターミナルで以下を実行します。

   ```bash
   npm install
   npm run build
   ```

4. ブラウザで `http://localhost/denkaru-react/login.php` にアクセスします。
5. 学習用のログイン暗証番号を使用してログインします。
6. メニューからReact版の患者管理画面や、既存の申し送り掲示板を利用します。

## Reactの編集方法

Reactの主なコードは以下のファイルにあります。

- `src/App.jsx`
- `src/style.css`

編集後、統合版に変更を反映するには、プロジェクトフォルダで `npm run build` を実行してください。

`npm run dev` はViteの開発用サーバーでの確認に使用します。PHPのログイン・掲示板を含めた統合動作確認には、ビルド後にXAMPP経由でアクセスしてください。

## データ保存について

React側の患者データとリハビリ介入記録は、ブラウザの `localStorage` に保存されます。既存のPHP掲示板とは保存先が異なります。

実在する患者情報や個人情報は入力しないでください。
